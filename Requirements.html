Motion System requirements

Install Python, then install the packages listed in requirements.txt:

python -m pip install -r requirements.txt

The dashboard QR code opens the dashboard on a phone on the same Wi-Fi. It does not configure the IP Webcam app itself; use --source http://PHONE_IP:8080/video to select that app's stream.

Deploy on Render

  1. Push this project, including render.yaml, to a GitHub repository.
  2. In Render, choose New > Blueprint and connect that repository.
  3. Deploy the motion-system web service defined in the blueprint. Render provides its HTTPS address and a generated dashboard password in the service's environment settings.
  4. Open the Render HTTPS address on your phone, sign in, then choose Connect phone camera and allow camera access.

For deployment, the QR code points to the Render HTTPS address. Motion snapshots are stored on the service's local disk and may not persist through a redeploy or restart.

Connect a phone camera

  1. Start the app on a computer connected to the same Wi-Fi network as your phone.
  2. Open the app's printed HTTPS address on the phone and select Connect phone camera.
  3. Allow camera access when prompted. The phone must trust the TLS certificate; camera access is also allowed on localhost.

To serve HTTPS, provide a certificate and matching private key: python app.py --cert path\to\certificate.pem --key path\to\private-key.pem. Both options are required together.

For a separate IP camera app, start the app with python app.py --source http://PHONE_IP:8080/video. Set --password to protect the dashboard on a shared network.
